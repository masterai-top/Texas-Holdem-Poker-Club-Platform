# Texas Hold'em Poker Club Source Code Platform

A Texas Hold'em club platform reference built around a **Unity client, C++ server, MySQL and Redis**. Publicly described modules include clubs, alliances, private/friend games, invitations, hand history, voice/video chat, MTT, SNG, AOF, insurance and administration.

> **This preserves the online README's original positioning: materials from an operated platform, club + alliance + private-game systems, 10+ game modes and a full-source package. Operational and performance statements are project-owner claims and should be independently verified.**
