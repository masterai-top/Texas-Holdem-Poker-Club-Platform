# 德州撲克俱樂部源碼｜德州源碼 ｜德州私人局、聯盟與多人即時對戰

基於 **Unity 用戶端 + C++ 伺服器 + MySQL + Redis** 的德州撲克俱樂部平台資料。專案包含俱樂部、聯盟、私人局/朋友局、邀請、戰績、語音視訊、MTT、SNG、AOF、保險與後台管理等已公開功能，適合技術評估、部署研究與二次開發。

> 倉庫資料展示現有產品與程式碼結構；營運歷史、併發能力、支付接入與部署完整性請在使用前獨立核驗，並遵守所在地法律及平台規則。

## 核心功能

| 模組 | 已公開內容 |
| --- | --- |
| 俱樂部與聯盟 | 俱樂部、聯盟、成員與代理體系 |
| 私人局 | 私人桌、朋友局、邀請及多人即時牌桌 |
| 玩法 | 經典德州、6+短牌、奧馬哈、大鳳梨、MTT、SNG、AOF、德州牛仔 |
| 對局工具 | 保險、戰績、機器人、禮物、即時語音及視訊聊天 |
| 技術 | Unity/C# 用戶端、C++ 伺服器、MySQL、Redis、多語言資源 |
